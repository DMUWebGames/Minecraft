js/blocks.js - Definitions

export const BLOCK = { AIR: 0, GRASS: 1, DIRT: 2, ... };
                export function getBlockColor(blockId) { /* ... */ }
Constants: A simple enum mapping readable names to IDs. getBlockColor is a fallback utility used in older versions or debugging, though the current system uses UVs/Textures.

index.html - Structure

<canvas id="webgpu-canvas"></canvas>
                <div id="crosshair"></div>
                <div id="hotbar">...</div>
DOM Elements:
- Canvas: The WebGPU render target.
- Crosshair: A simple CSS-styled div centered on screen for aiming.
- Hotbar: A UI overlay showing the currently selected block type.

style.css - Styling

body { display: grid; place-items: center; ... }
#hotbar { position: fixed; bottom: 20px; ... }
.slot.active { border: 2px solid white; ... }
UI Layout:
- Centers the canvas.
- Positions the hotbar at the bottom center.
- Uses pointer-events: none on UI overlays so clicks pass through to the canvas.
- Defines the "active" class style to highlight the selected slot.
