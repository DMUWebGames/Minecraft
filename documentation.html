WebGPU Minecraft Clone - Technical Documentation

This document provides a detailed, line-by-line explanation of the codebase for the WebGPU Minecraft clone. It is intended for tutors and developers to understand the architecture, rendering pipeline, and game logic.

                const vertexBufferLayout = {
                    arrayStride: 32, 
                    attributes: [
                        { shaderLocation: 0, offset: 0, format: "float32x3" }, // Position
                        { shaderLocation: 1, offset: 12, format: "float32x2" }, // UV
                        { shaderLocation: 2, offset: 20, format: "float32x3" } // Normale
                    ]
                };
Memory Layout: This tells the GPU how to read the data.
- Stride 32: Each vertex takes up 32 bytes (3*4 + 2*4 + 3*4).
- Attributes: Position starts at byte 0, UV at byte 12, Normal at byte 20.

Shader Code (WGSL)

    
                const shaderCode = `
                struct Uniforms { mvpMatrix: mat4x4 };
                @binding(0) @group(0) var uniforms: Uniforms;

                @binding(1) @group(0) var textureSampler: sampler;
                @binding(2) @group(0) var textureData: texture_2d;

                struct Light { pos: vec3, intensity: f32, };
                struct LightsBuffer {
                    count: u32,
                    pad1: u32, pad2: u32, pad3: u32, 
                    lights: array,
                };
                @binding(3) @group(0) var lightsData: LightsBuffer;
Shader Structures & Bindings:
- Uniforms: Holds the transformation matrix.
- Sampler/Texture: Bound for reading block textures.
- Light System: We define a struct for point lights. LightsBuffer uses a fixed-size array (max 16 lights) and includes padding (pad1, pad2, pad3) to adhere to WebGPU's strict memory alignment rules for uniform buffers (16-byte alignment for structs). 
        
                struct VertexInput {
                    @location(0) position: vec3,
                    @location(1) uv: vec2,
                    @location(2) normal: vec3, 
                };
                struct VertexOutput {
                    @builtin(position) position: vec4,
                    @location(0) uv: vec2,
                    @location(1) normal: vec3,
                    @location(2) worldPos: vec3, 
                };
Vertex Stage Data: Input matches the vertexBufferLayout. Output passes data to the fragment shader. @builtin(position) is the final clip-space position. worldPos is passed to calculate lighting distances. 
        
                @vertex
                fn vertexMain(input: VertexInput) -> VertexOutput {
                    var output: VertexOutput;
                    output.position = uniforms.mvpMatrix * vec4(input.position, 1.0);
                    output.uv = input.uv;
                    output.normal = input.normal;
                    output.worldPos = input.position; 
                    return output;
                }
Vertex Shader Logic: The core transformation. It multiplies the local vertex position by the Model-View-Projection matrix to place it correctly on the screen. It passes other attributes through unchanged. 
        
                @fragment
                fn fragmentMain(@location(0) uv: vec2, @location(1) normal: vec3, @location(2) worldPos: vec3,) -> @location(0) vec4 {

                let texColor = textureSample(textureData, textureSampler, uv);

                var totalLight = vec3(0.15, 0.15, 0.15); 

                let sunDir = normalize(vec3(0.6, 1.0, 0.4));
                let sunDiffuse = max(dot(normal, sunDir), 0.0);
                totalLight += vec3(0.4, 0.4, 0.35) * sunDiffuse;
Fragment Shader - Base Lighting:
1. Sampling: Read the pixel color from the texture atlas.
2. Ambient: A base light level (0.15) so shadows aren't pitch black.
3. Sun: A simple directional light. dot(normal, sunDir) calculates how much the face points towards the sun. 
        
                for (var i: u32 = 0u; i < lightsData.count; i++) {
                    let light = lightsData.lights[i];
                    let toLight = light.pos - worldPos;
                    let dist = length(toLight);
                    let dir = normalize(toLight);

                    let attenuation = light.intensity / (1.0 + dist * dist);
                    let diffuse = max(dot(normal, dir), 0.0);
                    totalLight += vec3(1.0, 0.55, 0.1) * diffuse * attenuation;
                }
Point Lights Loop: Iterates through dynamic lights (lamps).
- Attenuation: Light fades with distance squared (1.0 + dist*dist).
- Diffuse: Standard Lambertian reflection.
- Color: We hardcode an orange tint for lamps. 
        
                let finalLight = clamp(totalLight, vec3(0.0), vec3(1.0));
                return vec4(texColor.rgb * finalLight, texColor.a);
                }`;
Final Output: We clamp lighting to prevent over-exposure and multiply the texture color by the calculated light value. This returns the final pixel color.

Pipeline & Resources

    
                const pipeline = device.createRenderPipeline({
                layout: 'auto',
                vertex: { module: shaderModule, entryPoint: 'vertexMain', buffers: [vertexBufferLayout] },
                fragment: { module: shaderModule, entryPoint: 'fragmentMain', targets: [{ format }] },
                primitive: { topology: 'triangle-list', cullMode: 'none' },
                depthStencil: { depthWriteEnabled: true, depthCompare: 'less', format: 'depth24plus' },
                });
Pipeline Creation: This connects all the pieces.
- Primitive: We draw triangles. cullMode: 'none' means we draw both sides of triangles (useful for debugging, though usually 'back' is better).
- DepthStencil: Essential for 3D so objects further away don't draw over closer objects. 
    
                const uniformBuffer = device.createBuffer({ size: 64, usage: GPUBufferUsage.UNIFORM | GPUBufferUsage.COPY_DST });
                const lightsBuffer = device.createBuffer({ size: 272, usage: GPUBufferUsage.UNIFORM | GPUBufferUsage.COPY_DST });
Uniform Buffers:
- Uniform (64 bytes): Fits one 4x4 matrix (64 bytes).
- Lights (272 bytes): Calculated size for the light array (Header + 16 lights * struct size).
